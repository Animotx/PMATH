Cazie Auto Login Helper (unpacked Chrome extension)

Install:
1. Extract this ZIP to a folder.
2. Open chrome://extensions and enable Developer mode.
3. Choose Load unpacked and select the extracted folder.

Behavior:
- Runs only on https://cazie-s.onrender.com/.
- On a login form, waits for Chrome or your password manager to fill both fields, then clicks the form submit button once.
- Does not save credentials, alter the username/password, or enter activation codes.
- If the site reports an error, it stops and leaves the form for you to correct.
- It does not automate activation, navigation to the game, or flag answers.
