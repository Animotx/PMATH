# PMath100 Careful Auto Solver

## Install in Chrome

1. Extract or keep this folder somewhere permanent on your computer.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode**.
4. Select **Load unpacked** and choose this folder (`pmath100-careful-solver`).
5. Open or reload `https://pmath100.com/games-mathproblem`.

The solver panel appears on the game page. It auto-starts; use **Stop** to pause and **Start** to resume. It submits only when the image passes its confidence checks and skips uncertain images.

To apply future edits, return to `chrome://extensions` and click the extension's reload button, then reload the game tab.

The extension runs only on HTTPS pages matching `pmath100.com/games-mathproblem` and requests no broad browser permissions.
